# 🧠 My Small Language Model

A Small Language Model (SLM) built from scratch for text generation. 
The project demonstrates the basic workflow of training and using a language model 
to generate text from a given prompt.

## 🚀 Project Overview

This project is a custom Small Language Model designed to generate text based on 
user-provided prompts.

The model is integrated with a simple Streamlit web interface where users can 
enter a prompt and generate text interactively.

## ✨ Features

- 🧠 Custom Small Language Model
- ✍️ Prompt-based text generation
- 🌐 Interactive Streamlit web interface
- 🎛️ Adjustable response length
- 🎨 Creativity control
- 🔝 Top-K sampling
- ⚡ CPU-based inference
- 💾 Trained model checkpoint
- 🐍 Python and PyTorch based implementation

## 🖥️ Project Interface

The project provides a simple interface where users can:

1. Enter a text prompt
2. Adjust response length
3. Control creativity
4. Set Top-K value
5. Generate text using the trained model

## 🛠️ Technologies Used

- PyTorch

- Natural Language Processing (NLP)
